# 宿題提出通知 セットアップ手順

## 目的

受講生がポータルで宿題を提出したら、講師の公式LINEグループに通知し、講師はNotionで提出内容を確認できる運用にするための設計メモです。

## 想定構成

1. ポータルの宿題提出フォームが Supabase `submissions` テーブルへ insert する
2. Supabase の insert をトリガーに n8n の Webhook を呼び出す
3. n8n が LINE Messaging API で講師グループへ PUSH 通知する
4. n8n が Notion API で確認用データベースへページを作成する

## 必要な認証情報

以下は未取得・要手配です。このリポジトリには保存しません。

- LINE Messaging API チャネルアクセストークン
- LINE 通知先グループID
- Notion Integration Token
- Notion 確認用データベースID
- n8n の Supabase Webhook 受信設定

## 本リポジトリで完了している前提

- `supabase/migrations/20260704_meeting_0703.sql` に `submissions` テーブル定義とRLSを追加済み
- 動画レッスン内の各モジュールに宿題提出フォームを追加済み
- フォーム送信時に `submissions` へ insert される実装済み

## 未着手部分

- n8n ワークフロー構築
- LINE Messaging API のPUSH通知実装
- Notion API のページ作成実装
- Supabase insert イベントから n8n Webhook を呼ぶ設定

## 通知メッセージ案

```
【宿題提出】
受講生: {{student_name}}
Module: {{module_id}}
タイトル: {{title}}
URL: {{url}}
メモ: {{memo}}
提出日時: {{created_at}}
```

## 運用メモ

Supabase SQL Editorでマイグレーションを手動適用したあと、n8n側で `submissions` の insert を受け取るWebhookを作成します。認証情報がそろうまでは、ポータル内の提出履歴確認のみで運用できます。
