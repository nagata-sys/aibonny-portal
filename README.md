# AIBONNY スクールポータル

AIBONNY スクール0期（2ヶ月講義＋4ヶ月実践）の **動画・宿題・日報・セミナー予約** を
1つにまとめて一元管理する受講生ポータルです。会員ごとにログインし、自分専用のマイページが開きます。

> 「動画を確認する場所」と「宿題・やるべきこと」を、このページを見れば必ず分かる状態にする —— がコンセプト。
> スクール全体設計（メイン講義 L01〜L16 → 3ゲート / 週次タスク / 日報）を反映しています。
> メイン講義とは別に、AIツールの使い方を解説する「その他教材」（ツールライブラリ）も常時公開しています。

---

## ログイン

会員番号・パスワードは **Supabase** で管理しています（パスワードはハッシュ化）。
ログインすると本人専用のマイページが開きます。

> ログイン情報や会員追加などの運営手順は、社内の非公開ドキュメント `運用手順.md` を参照してください
> （このリポジトリには含まれていません）。

## 画面構成

| 画面 | 内容 |
|------|------|
| ホーム | 全体進捗・進捗ステッパー・**次にやる1本**・今週のやること・**予約済みセミナー**・クイックリンク |
| 動画レッスン | 「メイン講義」「その他教材」のタブ選択式。各動画は1講義1ページで開き、章のサマリーと宿題提出フォームを併設。YouTube埋め込み動画は IFrame Player API で90%再生を自動検知し、視聴済みになる |
| ロードマップ | 1ヶ月目・2ヶ月目・自走フェーズの到達目標と現在地を可視化 |
| セミナー予約 | 講師ごとの各テーマ枠に応募。**Googleカレンダーに追加**できる |
| コミュニティ | LINEリンク・**日報フォーム（LINEコピー機能つき）**・週報・進捗グラフ・ストリーク・称号バッジ |
| リソース | 困ったらこの3本・テンプレ集・Notionリンク |

**視聴チェック・宿題・日報・セミナー予約はすべて Supabase に保存**され、端末をまたいで同期します。
運営は Supabase ダッシュボードで全受講生の進捗・日報・予約を一覧できます。

ヘッダー右上の受講生チップから、基本情報と返金・延長伴走の参加要件チェックを確認できます。

## コンテンツの編集（`assets/data.js`）

### 動画URLを入れる
各 `video` の `url` に YouTube / Vimeo の **埋め込み(embed)URL** を貼ります。
```js
{ id: "9-1", title: "内製化の完成と効果測定", min: 20, type: "hands",
  url: "https://www.youtube.com/embed/xxxxxxxxxxx" },   // ← ここ
```
- YouTube の場合：動画URLの `watch?v=ID` を `embed/ID` に変える
- 空 `url: ""` のままなら「準備中」と表示されます
- **YouTube埋め込みURL（`https://www.youtube.com/embed/ID`）を推奨**します。YouTube埋め込みは IFrame Player API により90%再生した時点で自動的に視聴済みになります（Vimeoなど他埋め込みは自動検知の対象外で、手動の「視聴済みにする」ボタンのみ有効です）

### その他教材を追加する（`extraVideos`）
メイン講義（L01〜L16）とは別に、AIツールの使い方を解説するツールライブラリは `extraVideos` 配列に追記すると「動画レッスン」→「その他教材」タブにカテゴリ別（LLM / AIコーディング / AI自動化 / AIエージェント / AIクリエイティブ / 音声入力 / 情報管理）で表示されます。
```js
extraVideos: [
  { id: "tool-notion", title: "Notion", cat: "情報管理", required: true, min: 15, url: "https://www.youtube.com/embed/xxxxxxxxxxx" },
],
```
- `id`（一意なID）・`title`（タイトル）・`cat`（カテゴリ名）・`required`（必修=true / 選択=false）・`min`（分・任意）・`url`（埋め込みURL）を指定します
- こちらも YouTube埋め込みURLを推奨します（自動視聴検知が効きます）

### リンク・ロゴ・タスクなど
- `links`：公式LINE・進捗ダッシュボード・Zoom のURL（未設定は「（未設定）」表示）
- ロゴ：`assets/aibonny-logo.png` を同名の透過PNGで上書き
- `tasks`（週ごとの宿題）・`templates`・`rescue` も配列を編集

## 運営オペレーション（Supabase）

会員の追加・パスワードリセット・セミナー枠追加などの SQL 手順、ログイン情報は、
社内の非公開ドキュメント `運用手順.md`（このリポジトリには含めない）にまとめています。

`assets/config.js` の URL・公開鍵はフロントに置いて問題ありません（データは Supabase の RLS で本人のみアクセス可）。

今回追加された `submissions`、`weekly_reports`、`reports.hours` は、`supabase/migrations/20260704_meeting_0703.sql` を Supabase SQL Editor で手動実行して適用します。このリポジトリはフロントのみでサービスロールキーを持たないため、自動マイグレーションは行いません。

## 公開方法

静的サイト＋Supabase（ブラウザから直接接続）なので、そのまま静的ホスティングに置けます。

### 公開URL（GitHub Pages）
https://ito-ops.github.io/aibonny-portal/

### ローカルで確認
```bash
python3 -m http.server 4173
```
→ ブラウザで `http://localhost:4173` を開く

### 公開・更新の流れ
1. 変更を `main` ブランチにプッシュすると GitHub Pages が自動で再デプロイされます
2. **Settings → Pages** で `main` ブランチ／`/ (root)` を公開する設定になっています
3. 上記の発行URLを受講生に共有してください

## 補足

- セミナー予約時の「カレンダーに追加」は、Googleカレンダーに予定を**ワンクリックで登録**するリンク方式です。
  応募と完全同時の自動登録（OAuth連携）にしたい場合は、別途Google連携の追加実装が必要です。
- 進捗の全体集計をさらに自動化したい場合は、設計どおり **Supabase → n8n** で日報リマインドやダッシュボード更新につなげられます。
