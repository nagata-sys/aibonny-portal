# AIBONNY スクールポータル

AIBONNY 個別伴走プラン（3ヶ月・全12回）の **動画・宿題・スケジュール・日報・セミナー予約** を
1つにまとめて一元管理する受講生ポータルです。会員ごとにログインし、自分専用のマイページが開きます。

> 「動画を確認する場所」と「宿題・やるべきこと」を、このページを見れば必ず分かる状態にする —— がコンセプト。
> スクール全体設計（Deal-First / 8モジュール→3ゲート / 週次カレンダー / 日報）を反映しています。

---

## ログイン

会員番号・パスワードは **Supabase** で管理しています（パスワードはハッシュ化）。
ログインすると本人専用のマイページが開きます。

> ログイン情報や会員追加などの運営手順は、社内の非公開ドキュメント `運用手順.md` を参照してください
> （このリポジトリには含まれていません）。

---

## 画面構成

| 画面 | 内容 |
|------|------|
| ホーム | 全体進捗・進捗ステッパー・**次にやる1本**・今週のやること・**予約済みセミナー**・クイックリンク |
| 動画レッスン | 8モジュール（Module 0〜7）の一本道カリキュラム。視聴チェック＆プレイヤー内蔵 |
| セミナー予約 | 講師ごとの各テーマ枠に応募。**Googleカレンダーに追加**できる |
| やること | 今週の宿題・毎日のルーティン（日報/AI発信）・全3ヶ月分のタスク |
| スケジュール | 1on1／グループセミナー／成果発表会の全行程を**開講日から日付自動計算** |
| コミュニティ | LINEリンク・**日報フォーム（LINEコピー機能つき）**・ストリーク・称号バッジ・返金要件チェック |
| リソース | 困ったらこの3本・テンプレ集・Notionリンク |

**視聴チェック・宿題・日報・セミナー予約はすべて Supabase に保存**され、端末をまたいで同期します。
運営は Supabase ダッシュボードで全受講生の進捗・日報・予約を一覧できます。

## コンテンツの編集（`assets/data.js`）

### 動画URLを入れる
各 `video` の `url` に YouTube / Vimeo の **埋め込み(embed)URL** を貼ります。
```js
{ id: "0-1", title: "オリエン: 3ヶ月で…", min: 8, type: "concept",
  url: "https://www.youtube.com/embed/xxxxxxxxxxx" },   // ← ここ
```
- YouTube の場合：動画URLの `watch?v=ID` を `embed/ID` に変える
- 空 `url: ""` のままなら「準備中」と表示されます

### リンク・ロゴ・タスクなど
- `links`：公式LINE・進捗ダッシュボード・Zoom のURL（未設定は「（未設定）」表示）
- ロゴ：`assets/aibonny-logo.png` を同名の透過PNGで上書き
- `tasks`（週ごとの宿題）・`schedule`（カレンダー）・`templates`・`rescue` も配列を編集

## 運営オペレーション（Supabase）

会員の追加・パスワードリセット・セミナー枠追加などの SQL 手順、ログイン情報は、
社内の非公開ドキュメント `運用手順.md`（このリポジトリには含めない）にまとめています。

## 公開方法

静的サイト＋Supabase（ブラウザから直接接続）なので、そのまま静的ホスティングに置けます。

### 公開URL（GitHub Pages）
https://ito-ops.github.io/aibonny-portal/

### ローカルで確認
```bash
python3 -m http.server 4173
```
→ ブラウザで `http://localhost:4173` を開く

### 公開・更新の流れ
1. 変更を `main` ブランチにプッシュすると GitHub Pages が自動で再デプロイされます
2. **Settings → Pages** で `main` ブランチ／`/ (root)` を公開する設定になっています
3. 上記の発行URLを受講生に共有してください

## 補足

- セミナー予約時の「カレンダーに追加」は、Googleカレンダーに予定を**ワンクリックで登録**するリンク方式です。
  応募と完全同時の自動登録（OAuth連携）にしたい場合は、別途Google連携の追加実装が必要です。
- 進捗の全体集計をさらに自動化したい場合は、設計どおり **Supabase → n8n** で日報リマインドやダッシュボード更新につなげられます。
